# Basketball Manager 26 support

Support for the Unity macOS basketball management game, bundle identifier
`com.romandivkovic.basketballmanager`.

## Starting a career

Choose **Create account** to create a local manager account on your Mac. Save
the recovery code shown when the account is created. Then start a new career,
create your coach and choose a team from a generated league.

Accounts and career saves are stored locally on your computer. This version
does not synchronize accounts or saves between devices.

## Importing a league

Choose **Import** and select `teams.csv`, `players.csv` and any supported draft
CSV files using the macOS file chooser. Use the in-game information button and
CSV template to check the required structure. Each selected file must be no
larger than 5 MB.

## Reporting a problem

[Open a support issue](https://github.com/RomanDivkovic/basketball-manager/issues/new)
and include the game version, macOS version and steps that reproduce the
problem. A screenshot can help explain a visual issue. GitHub issues are
public; account passwords and recovery codes are not needed for support.
